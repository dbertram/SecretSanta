    3Your delivery helper

    Connect your Gmail account when you’re ready to send. Authorization lasts for this visit only.

    Google OAuth settings

    Public configuration, not a password. Need a new client ID? Open the Google Cloud Console:

    1. Create or select a project and enable the Gmail API.
    2. Configure Google Auth Platform branding and consent. For personal use, choose External and add your Gmail address as a test user under Audience.
    3. Under Data Access, add the Gmail send (gmail.send) and email identity (userinfo.email) scopes.
    4. Under Clients, create a Web application. Add this page’s origin (scheme, hostname, and port, without a path) to Authorized JavaScript origins. For local use, add http://localhost and http://localhost:8787.
    5. Copy the client ID here and click Save client ID.
